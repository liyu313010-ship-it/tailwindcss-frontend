# TailwindCSS 前端项目

基于 TailwindCSS + PostCSS + Autoprefixer 的前端项目模板，包含自定义表单样式配置。

## 技术栈

- TailwindCSS 3.x
- PostCSS
- Autoprefixer
- @tailwindcss/forms

## 目录结构

```
src/          - 源码（input.css 入口）
pages/        - 页面
dist/         - 构建产物（output.css）
images/       - 图片资源
```

## 构建

```bash
npm install
npm run tw:build
```
